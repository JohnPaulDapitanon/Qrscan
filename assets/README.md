# Assets & Design Directory

This folder contains all the visual, design, and media assets used across the **Vehicle Safe LGU-Monitor** web application.

## Directory Structure

```
assets/
└── images/                     # Graphic & Photographic Assets
    ├── destinations/           # Featured Tourism & Transit Destinations
    │   ├── baywalk.jpg         # City Baywalk & Boulevard
    │   ├── dahican.png         # Dahican Beach
    │   ├── Pujada.png          # Pujada Bay
    │   ├── sleepingdino.jpg    # Sleeping Dinosaur
    │   ├── Subangan.jpg        # Subangan Heritage Museum
    │   └── waniban.jpg         # Island Hopping (Waniban & Pujada Bay)
    │
    ├── logo/                   # Brand & City Logos
    │   ├── feel-mati.png       # Official Feel MATI Banner
    │   └── mati-logo.png       # Official City of Mati Seal
    │
    ├── patterns/               # Background Patterns & Textures
    │   └── lgu-pattern.svg     # Geometric Header Pattern
    │
    └── profiles/               # Operator Identity Photos
        └── operator-avatar.jpg # Default Verified Operator Avatar
```
